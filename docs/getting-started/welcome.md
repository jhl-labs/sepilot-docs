SEPilot 문서에 오신 것을 환영합니다!

Welcome to SEPilot Documentation!

## About SEPilot

SEPilot은 개발자를 위한 지능형 개발 지원 도구입니다.

SEPilot is an intelligent development assistance tool for developers.

이 문서 저장소는 SEPilot Desktop의 RAG(Retrieval-Augmented Generation) 시스템에서 활용되어, 개발 활동 중 필요한 정보를 빠르고 정확하게 제공합니다.

This documentation repository is utilized by SEPilot Desktop's RAG (Retrieval-Augmented Generation) system to provide quick and accurate information during development activities.

## How RAG Uses This Documentation

SEPilot Desktop의 RAG 시스템은 이 문서들을 어떻게 활용하나요?

How does SEPilot Desktop's RAG system utilize these documents?

1. **자동 인덱싱 (Automatic Indexing)**: 모든 문서가 자동으로 인덱싱되어 검색 가능한 지식 베이스를 형성합니다.
   - All documents are automatically indexed to form a searchable knowledge base.

2. **컨텍스트 기반 검색 (Context-Based Search)**: 개발 중인 코드와 질문에 따라 관련 문서를 자동으로 찾습니다.
   - Automatically finds relevant documents based on code being developed and questions asked.

3. **지능형 응답 (Intelligent Responses)**: 문서 내용을 바탕으로 정확하고 맥락에 맞는 답변을 제공합니다.
   - Provides accurate, context-aware responses based on document content.

4. **실시간 업데이트 (Real-time Updates)**: 문서가 업데이트되면 RAG 시스템도 자동으로 최신 정보를 반영합니다.
   - RAG system automatically reflects the latest information when documents are updated.

## Documentation Best Practices

문서 작성 시 베스트 프랙티스:

Best practices for writing documentation:

- **명확성 (Clarity)**: 명확하고 이해하기 쉬운 언어 사용
  - Use clear and easy-to-understand language
  
- **완전성 (Completeness)**: 필요한 모든 정보 포함
  - Include all necessary information
  
- **예제 (Examples)**: 실용적인 예제 제공
  - Provide practical examples
  
- **최신성 (Up-to-date)**: 정보를 최신 상태로 유지
  - Keep information up-to-date
  
- **구조화 (Organization)**: 논리적인 구조로 정리
  - Organize with logical structure
