# SEPilot Documentation Repository

개발 활동에서 필요한 문서들을 모아놓은 전용 Repository입니다.

A dedicated repository for collecting documents needed for development activities.

## Purpose

이 저장소는 SEPilot Desktop의 RAG(Retrieval-Augmented Generation) 시스템에서 활용하기 위한 문서를 관리합니다.

This repository manages documentation to be utilized by the RAG (Retrieval-Augmented Generation) system in SEPilot Desktop.

## Structure

```
sepilot-docs/
├── docs/                    # Main documentation directory
│   ├── getting-started/     # Getting started guides
│   ├── development/         # Development guides and best practices
│   ├── api/                 # API documentation
│   ├── architecture/        # Architecture and design documents
│   ├── tutorials/           # Step-by-step tutorials
│   └── reference/           # Reference materials
├── templates/               # Documentation templates
└── README.md               # This file
```

## Contributing

문서를 추가하거나 수정할 때는 다음 가이드라인을 따라주세요:

When adding or modifying documents, please follow these guidelines:

1. Use Markdown format for all documentation
2. Place documents in the appropriate category directory
3. Use clear and descriptive file names
4. Include proper headings and structure
5. Add metadata at the top of each document (title, date, category)

## Documentation Categories

Guides for new users or developers to get started

### Reference

## Usage with RAG

이 저장소의 문서들은 SEPilot Desktop의 RAG 시스템에 의해 자동으로 처리되어, 개발자들에게 컨텍스트 기반의 지능형 지원을 제공합니다.

Documents in this repository are automatically processed by SEPilot Desktop's RAG system to provide context-based intelligent assistance to developers.
